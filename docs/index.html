Features

Everything you need.
Nothing in the way.

A fast, focused chat window for the models on your machine, with the tools you reach for every day.

Attach files

Local models can't read your disk. Add files to a message and ask questions about them, right in the chat.

Search every chat

Chats are saved as you go, like in ChatGPT or Claude. Star the ones that matter and find anything with Ctrl+K.

Thinking mode

Switch on thinking and watch reasoning models work through hard problems step by step.

Context meter

See how much of the model's memory a conversation is using before it starts to forget.

Code that copies

Answers render as clean markdown, with a copy button on every code block.

Any Ollama server

Uses Ollama on this computer by default. Point it at another machine on your network from Settings.

Private by design

Your data never
leaves home.

The convenience of a cloud assistant, without handing your prompts, files or chats to anyone. It's safe for work you'd never paste into a website.

  • Runs on your machine

    Every request goes to your own Ollama server. No cloud in between.

  •

    Files stay with you

    Attachments are read in your browser and sent only to your model.

  •

    Chats saved locally

    History is stored on your device, not on someone else's server.

  •

    No accounts, no tracking

    No sign-up, no API keys, no analytics.

Get started

Up and running
in three steps.

No accounts and no API keys. If Ollama runs on your computer, so does TOKN.

  1. 01

    Install Ollama

    Download it from ollama.com and start its server with TOKN allowed as an origin, so the browser can reach it.

    $ OLLAMA_ORIGINS='*' ollama serve
  2. 02

    Pull a model

    Grab any model from the Ollama library. Qwen3 0.6B is small, fast, and a good first pick.

    $ ollama pull qwen3:0.6b
  3. 03

    Start chatting

    Open TOKN, pick the model from the menu at the top, and say hello.
