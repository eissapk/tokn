Explain how to use git rebase to clean up my commits.
AI Agent

Git rebase lets you move or combine commits, helping you keep a cleaner, more linear history. Here's a simple guide:

1. Start on your branch

Make sure you're on the branch you want to clean up:

git checkout feature-branch

2. Rebase onto the target branch

Rebase your branch onto the latest main:

git rebase main

3. Resolve conflicts if needed

Fix conflicts, stage the files, then continue:

git add <file> git rebase --continue

4. Squash or edit commits

Use an interactive rebase when you want to combine, rename, or remove commits:

git rebase -i HEAD~n

5. Push the cleaned history

If the branch was already pushed, update it safely with:

git push --force-with-lease
That's it. Your commit history will be cleaner.
